# Peter-Weyl logical anisotropy: unbiased return-kernel result

Status: **exact first-order support no-go + tested finite 32-column second-order return kernel; static effective gap/RG flow still open**.

This note tests whether the accidental logical-pseudospin `SU(2)` of the Bell-gluing Heisenberg parent survives the actual Euclidean Peter-Weyl geometry dynamics.

The answer is sharply split:

```text
mirror Z2          -> survives
pseudospin SU(2)   -> strongly broken in the first nonzero return channel
```

The calculation does **not** identify the return kernel with a static Schrieffer-Wolff Hamiltonian. It is an exact structural and short-time statement.

---

## 1. Exact first-order protection

Let `P` project onto the all-`j=1/2` logical geometry-qubit sector of the K5 Peter-Weyl habitat.

Every oriented Euclidean triangle term contains fundamental holonomy hits on the loop edges. A fundamental hit changes

```text
j -> j +/- 1/2,
```

while the volume operator does not change the edge spin.

Therefore a single Euclidean action cannot return an all-`j=1/2` logical state to the same sector:

```text
P H_E P = 0.
```

`scripts/peter_weyl_logical_anisotropy_gate.py` verifies this on all 32 logical columns used in the environment-unbiased calculation. The maximum projected norm after one hit is exactly

```text
0.0.
```

Consequences:

- no first-order logical `X`, `Y` or `Z` field is generated by `H_E`;
- in particular, the mirror pair is not split at first order;
- the first possible pseudospin symmetry breaking appears only in a return channel.

## 2. First nonzero structural return kernel

For neighboring logical nodes 0 and 1 define

```text
H_01 = H_E,0 + H_E,1
```

using the physical sine ordering

```text
H_E^sine = (T-T^dagger)/(2i).
```

Because `P H_01 P=0`, the first nonzero projected return object is

```text
K_ret = P H_01^2 P.
```

Its matrix elements are Gram overlaps of first-action states:

```text
(K_ret)_ij = <H_01 i | H_01 j>.
```

This construction needs no fitted coefficient and no arbitrary energy denominator.

But this distinction is essential:

```text
K_ret != a proved static effective Hamiltonian.
```

A physical Schrieffer-Wolff/Feshbach Hamiltonian would require a justified constrained-theory resolvent.

## 3. Why the environment had to be traced

A first control fixed the other three logical K5 qubits to `K=0`. That gave a large anisotropy, but such a shape-polarized environment could itself select a preferred logical axis.

Therefore the decisive calculation averages over all

```text
2^3 = 8
```

logical states of nodes 2,3,4:

```text
Kbar_01
 = (1/8) Tr_{2,3,4}
   P(H_E,0+H_E,1)^2P.
```

The gate evaluates all

```text
4 pair states x 8 environment states = 32 logical columns.
```

The environment density matrix is proportional to the identity, so this partial trace does not prefer the `K=0` basis by construction.

```text
(X,Y,Z)_B -> (-X,+Y,-Z)_B.
```


Therefore the strong pseudospin anisotropy survives the maximally mixed environment trace.

This rules out the interpretation that the earlier large anisotropy was merely a `K_2=K_3=K_4=0` boundary-state artifact.

## 6. Exact S4 coarse reduction

The independent logical face-permutation twirl shows that diagonal tetrahedral `S4` symmetry removes local logical fields and label-axis artifacts but leaves two independent bilinear invariants:

```text
XX+ZZ
YY.
```

Therefore the environment-unbiased kernel reduces under full tetrahedral twirling to

```text
K_sym
 = c0 II
 + J_shape (XX+ZZ)
 + J_orient YY
```

with

```text
c0       = 14.318438270666093
J_shape  = (-0.5020918898145224 - 1.695852157212999)/2
         = -1.0989720235137607
J_orient =  2.5842530086520437.
```

The one surviving symmetry-allowed split is therefore

```text
Delta_aniso,ret
 = J_orient-J_shape
 = 3.6832250321658044.
```

This is the correct coarse structural anisotropy observable.

Mirror symmetry alone permits this split; it protects `chi=+/-1` degeneracy but does not enforce full Heisenberg pseudospin symmetry.

## 7. Exact short-time meaning without a resolvent

Although `K_ret` is not yet a static effective Hamiltonian, it has an exact dynamical interpretation.

Since `P H_E P=0`,

```text
P exp(-i t H_E) P
 = P - t^2 K_ret/2 + O(t^3)
```

in units with `hbar=1` for the displayed expansion.

For an initial logical state `|psi>`, the probability to leave the projected all-`j=1/2` sector begins as

```text
P_leak(t|psi)
 = t^2 <psi|K_ret|psi> + O(t^3).
```

Therefore the anisotropy is already a physical **state-dependent short-time leakage anisotropy** of the Euclidean Peter-Weyl dynamics, even before a static effective Hamiltonian is derived.

After `S4` twirling the four Bell-sector coefficients are approximately

```text
9.536241214986528
16.902691279318137
16.902691279318137
13.932129309041571.
```

So different logical pseudospin sectors have substantially different second-order leakage rates.

The finite result is now robust against the main obvious basis/environment objection:


Thus the exact Bell-gluing Heisenberg parent is a useful structural parent but is **not an exact symmetry of the Euclidean Peter-Weyl return dynamics**.

## 9. What remains genuinely open

```text

under the physically correct constrained resolvent / transfer kernel / RG flow?
```

A true low-energy effective operator must supply the intermediate-state weighting from the actual dynamics rather than silently setting every denominator to one.

The two possible outcomes are now sharp:

```text
Delta_aniso^eff -> 0
  -> accidental Heisenberg symmetry can re-emerge in the IR

  -> easy-axis/easy-plane mirror sector; use the massive/anistropic branch.
```

In either case mirror `Z2` itself remains separately protected by the tested selection rules.
