# Peter-Weyl logical anisotropy: unbiased return-kernel result

Status: **exact first-order support no-go + tested finite 32-column second-order return kernel; physical constrained resolvent/RG flow still open**.

This note tests whether the accidental logical-pseudospin `SU(2)` of the Bell-gluing Heisenberg parent survives the actual Euclidean Peter-Weyl geometry dynamics.

The result is sharply split:

```text
mirror Z2          -> survives
pseudospin SU(2)   -> strongly broken in the first nonzero return channel.
```

The calculation does **not** identify the return kernel with a static Schrieffer-Wolff Hamiltonian. It is an exact structural and short-time statement.

The numerical values below are the canonical values from the final environment-unbiased CI artifact and supersede provisional values from earlier revisions of the return-kernel gate.

## 1. Exact first-order protection

Let `P` project onto the all-`j=1/2` logical geometry-qubit sector of the K5 Peter-Weyl habitat.

Every oriented Euclidean triangle term contains fundamental holonomy hits on loop edges. A fundamental hit changes

```text
j -> j +/- 1/2,
```

while the volume operator does not change edge spin.

Therefore a single Euclidean action cannot return an all-`j=1/2` logical state to the same sector:

```text
P H_E P = 0.
```

`scripts/peter_weyl_logical_anisotropy_gate.py` verifies this on all 32 logical columns used in the environment-unbiased calculation. The maximum projected norm after one hit is exactly

```text
0.0.
```

Hence there is no first-order logical `X`, `Y` or `Z` field generated by `H_E`, and no first-order mirror splitting.

## 2. First nonzero structural return kernel


