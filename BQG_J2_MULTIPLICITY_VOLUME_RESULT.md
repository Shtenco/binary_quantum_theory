# First multiplicity-space geometry test: j=2

At \(j=2\),

\[
\dim\mathrm{Inv}_{SU(2)}(V_2^{\otimes4})=5,
\]

and the exact multiplicity theorem gives

\[
m_{[2,2]}=2.
\]

Thus the \([2,2]\) isotypic sector has dimension four,

\[
\mathbb C^2_{\rm mult}\otimes V_{[2,2]}.
\]

For any \(S_4\)-invariant operator \(O\), Schur's lemma implies

\[
\boxed{
O|_{[2,2]\text{-iso}}
=
A_2\otimes I_2.
}
\]

The first test uses the existing absolute-volume operator

\[
V=|Q|^{1/4}.
\]

If its restricted spectrum consists of two distinct doubly-degenerate eigenvalues, then the geometry already resolves the two multiplicity channels and supplies a canonical multiplicity eigenbasis.

This would not yet select the physical RG channel, but it would remove the need for an arbitrary basis inside the first multiplicity-two sector.
