# Preregistration: first constraint-generated Peter-Weyl Krylov span from the q=2 boundary

Status: **frozen before the first 160-column Gram rank is evaluated.**

## Target

Let `B={|b_i>}_{i=0}^{31}` be the frozen all-`j=1/2` K5 logical boundary basis and let `H_v^E`, `v=0..4`, be the existing regulator-safe Euclidean Peter-Weyl node constraints at `Jmax=5/2`.

Define the first outgoing family

\[
|g_{vi}\rangle=H_v^E|b_i\rangle,
\qquad v=0,\ldots,4,
\quad i=0,\ldots,31.
\]

There are 160 labelled columns before linear-dependence reduction.

The exact first-layer Gram is

\[
\boxed{
G_1[(v,i),(w,j)]
=\langle g_{vi}|g_{wj}\rangle.
}
\]

Its rank is exactly the dimension, at the declared numerical amplitude tolerance, of the odd Peter-Weyl subspace generated by one action of the five Euclidean constraints on the 32 q=2 boundary states.

No expected rank is frozen.

## Why this is the right compression diagnostic

The first constraint-generated Krylov carrier is

\[
\mathcal K_1
=\operatorname{span}\{B,H_0B,\ldots,H_4B\}.
\]

Doubled-spin parity makes the all-`j=1/2` boundary even and every `H_v^E B` odd. Therefore the two pieces are orthogonal and

\[
\boxed{
\dim\mathcal K_1
=32+\operatorname{rank}G_1.
}
\]

before any Lorentzian-even dressing is added.

This number determines the actual cost of the next Ritz/master calculation. It is scientifically preferable to assuming the naive upper bound `32+5*32=192`.

## Frozen consistency identities

For the node-diagonal `32 x 32` blocks

\[
G_{vv}[i,j]=G_1[(v,i),(v,j)],
\]

the five-node boundary master must satisfy

\[
\boxed{
M_E^{(B)}=\sum_{v=0}^{4}G_{vv}.
}
\]

For any two nodes,

\[
\operatorname{Gram}[(H_v+H_w)B]
=G_{vv}+G_{ww}+G_{vw}+G_{wv}.
\]

These are algebraic reconstruction identities and will be checked internally.

Use the same `Jmax=5/2`, same `PW.apply_H_cached_state`, same pruning threshold and same ordered 32 boundary basis as the preregistered five-node boundary master. The cutoff is inherited from the exact K5 Euclidean HH reachability wall and is not selected from this Gram spectrum.

## Outputs

## Pass/fail

Implementation PASS requires only:

- Hermiticity;
- positive semidefiniteness;
- boundary/outgoing parity orthogonality;
- exact reconstruction of the five-node boundary master from diagonal blocks;
- the declared 160 source labels are all evaluated.

**The rank is not a pass target.**

A low rank is computationally favorable but not more physically correct than a high rank.

## Scientific boundary

This gate measures the first generated Euclidean habitat only. It does not construct the zero projector, does not test Lorentzian cancellation in a parity-complete state, and does not imply a dark mode. Its role is to determine the smallest data-driven block-Krylov carrier on which the next master Ritz problem should be built.
