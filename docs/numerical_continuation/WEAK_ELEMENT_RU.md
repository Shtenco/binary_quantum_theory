# Слабая форма выбранного обратного элемента

Цель — проверить конкретный <psi,H_L phi> на одном общем spin wall=7. Полная reverse-колонка на всех выходах является отдельной задачей. Нельзя получить численно независимый тест простым присвоением conjugate(<phi,H_L psi>).

## Строгий алгебраический мост для идеального конечного кандидата

Пусть на одном конечном пространстве V=V†, H_E=H_E†, K=[V,H_E], а обратная holonomy реализована как сопряжённая матрица h†. Определим матрицы операторов

C(K)=K I−h(K I)h†, C(V)=V I−h(V I)h†.

Тогда C(K)_ij†=−C(K)_ji и C(V)_ij†=C(V)_ji. Здесь не требуется h h†=I. Если исходное определение h[h^-1,K] заменяется на K−hKh†, равенство с ним требует h h^-1=I на соответствующих векторах; при spin cutoff это нельзя предполагать глобально. На K(phi) замыкание h h^-1 численно проверено для всех четырёх рёбер; maximum error приведён в K_all_holonomy_closure.json.

Для R=sum epsilon_abc Tr(Ca(K) Cb(K) Cc(V)) получаем

<psi,R phi> = sum epsilon_abc sum_ijk <Cb(K)_kj Ca(K)_ji psi, Cc(V)_ki phi>,

<psi,R† phi> = −sum epsilon_abc sum_ijk <Cb(K)_kj Cc(V)_ji psi, Ca(K)_ki phi>.

Порядок факторов сохранён. Цикличность operator-valued trace не используется. Эти равенства позволяют пользоваться уже рассчитанными промежуточными образами psi и независимо новыми первыми образами phi, не вычисляя всю тройную reverse-колонку.

Если H_L=(R−R†)/(2i), соответствующий выбранный слабый элемент вычисляется из обеих сумм. Самосопряжённость всего H_L не используется как вход для присваивания результата. Сопряжённость примитивов — явная предпосылка и точная алгебраическая теорема для указанного идеального оператора; thresholded implementation остаётся приближением с незакрытым бюджетом ошибки.

## Что проверяет численный расчёт

- Новые CV(phi) и CK(phi) вычисляются независимо, на том же wall=7.
- Старые middle-образы psi берутся с проверенным fingerprint 32b0756b..., соответствующим исходным script bytes HEAD 54c5d907 и прежнему adapter.
- Слабые суммы считаются по всем 24 epsilon-словам, включая off-diagonal auxiliary indices.
- Результат сравнивается с conjugate ранее сохранённого <phi,H_L psi>; это сравнение, а не источник нового результата.

Даже совпадение не сертифицирует прямое исполнение nonlinear pruning routines на всех промежуточных reverse-состояниях. Это слабая проверка выбранного матричного элемента кандидата при указанных adjoint identities, не весь H_L и не physical Hilbert/refinement limit.
