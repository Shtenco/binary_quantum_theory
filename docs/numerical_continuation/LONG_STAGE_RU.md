# Большой этап численного продолжения BQG

Это снимок вычислительных свидетельств, не доказательство физического предела.

## Готовые данные

- Проверены и экспортированы 50/352 внутренних HE-колонок прямой части второго CK-этапа для 96 сохранённых упорядоченных входов сопряжённой ветви.
- Инвентаризированы 192/192 обратные голономические ветви: требуются 4016 дополнительных канонических HE-входов.
- Их распределение по заряженным узлам: (0,1): 1105; (0,2): 1032; (0,3): 1012; (0,4): 867. При источнике J2=1 имеется 1706 входов, при J2=3 — 2310; максимальный входной удвоенный спин равен 4. Стенка отсечения остаётся 7.
- 122/4016 обратные колонки восстановлены из исторических данных с точным совпадением аргументов и отпечатка 32b0756b…; новых обратных амплитуд этот проход пока не получил.
- Проверены все 1119 записей старого HE-кэша: ключи, отпечатки, конечность коэффициентов, сохранение J,M. Это проверка сохранённых данных, не повторная генерация амплитуд.
- Полных вторых CK-действий остаётся 0/96. Прямая обратная HL-колонка, полный бюджет ошибки, полное семейство ограничений, физическая история и взаимодействующий TT-полюс не получены.

## Локальный процесс

На момент подготовки снимка запущен расчёт всех недостающих прямых колонок с сохранением каждого результата. После успешного завершения прямого базиса локальный управляющий процесс должен перейти к недостающим обратным колонкам. Это процессы текущей рабочей среды, а не долговременный сервис GitHub; существование процесса следует проверять при следующем подключении. Публикуемые числа являются зафиксированным снимком.

## Границы результата

352 и 4016 относятся к двум разным частям конкретной второй CK-стадии на одном выбранном входе одного узла. Они не перечисляют все входы и узлы полного HL. Полный прямой порядок R требует отдельной сборки. Проверка сохранения J,M в уже спроецированных данных не заменяет проверку остатка вне проекции после полной суммы.

Пороговые удаления делают вычислительную реализацию нелинейной: тождества идеальных линейных операторов нельзя автоматически переносить на неё. Все оценки округления и отсечения должны учитываться отдельно. complete=false и physicalization_complete=false сохранены.

## Свидетельства

- SECOND_STAGE_CURRENT.json — проверенный снимок прямых колонок.
- SECOND_STAGE_INVERSE_INVENTORY.json — полный учёт 192 ветвей, без вычисления их HE-образов.
- SECOND_STAGE_INVERSE_REUSE.json — происхождение 122 сохранённых обратных колонок; их векторы пока не включены в переносимый архив.
- SECOND_STAGE_COVERAGE.json — снимок недостающих входов; не сертификат CK.
- ADDITIONAL_SECOND_STAGE_HE.json и MANIFEST.json — новые прямые векторы и SHA-256.
