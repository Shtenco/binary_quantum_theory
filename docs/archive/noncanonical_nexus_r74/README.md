# Noncanonical NEXUS R7.4 archive

This directory preserves historical AI benchmark material that previously lived on the active surface of the Binary Quantum Gravity repository.

It is **not part of the canonical BQG theory**, does not contribute to theory_gates.json, physicalization_gates.json, or depth6_frontier.json, and its workflows are intentionally archived here so they no longer run as active BQG CI.

The material is retained only for provenance and scientific history.
