## 3. Exact restricted-domain no-go

\[

\[
\boxed{
\ker(H_{E,0}+H_{E,1})\cap\mathcal H_{log}=\{0\}.

\[
\ker H_{E,0}\cap\ker H_{E,1}

\ker(H_{E,0}+H_{E,1}),

\[
\boxed{
\ker H_{E,0}\cap\ker H_{E,1}\cap\mathcal H_{log}=\{0\}.

\]

This is stronger than the old statement `P_log H_E P_log=0`: the direct-return matrix vanishes by parity while the complete outgoing constraint map has **no zero vector** in the same input carrier.
