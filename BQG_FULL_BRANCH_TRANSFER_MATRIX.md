# BQG full branch-transfer matrix

The correct finite representation-RG object is not a single overlap with the
lowest master channel.

For every source master branch \(r\) and target master branch \(s\), define

\[
\boxed{
F_j^{rs}
=
\frac12\operatorname{Tr}
\left(
P^{\rm block}_{j,r}
P^{\rm master}_{j+1/2,s}
\right).
}
\]

For fixed source branch \(r\),

\[
\sum_s F_j^{rs}=1
\]

because the target master channels resolve the full \([2,2]\) isotypic sector.

Thus \(F_j\) is the canonical finite branch-transfer matrix generated by the
microscopic binary refinement and resolved by the actual constraint dynamics.

The physically continuous trajectory should be determined from the sequence
of these matrices, not by the ad hoc rule "always choose the lowest local
master eigenvalue".

Two useful global path scores are:

\[
S_{\rm log}(\{r_j\})
=
-\sum_j \log F_j^{r_j r_{j+1}},
\]

and the bottleneck score

\[
B(\{r_j\})
=
\min_j F_j^{r_j r_{j+1}}.
\]

A genuine microscopic/master incompatibility would require that even the
optimal branch trajectory retains order-one mismatch at large \(j\).

Branch switching with near-unit best overlaps instead means the local
eigenvalue ordering is not the correct physical RG label.
