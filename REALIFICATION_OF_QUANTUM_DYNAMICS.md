# 1. Realifying a complex vector

Write

\[
\psi=x+iy,
\]

where `x` and `y` are real vectors.

Store the same state as one real vector

\[
\boxed{
v=
\begin{pmatrix}
x\\y
\end{pmatrix}.
}
\]

Define the real complex-structure operator

\[
\boxed{

\begin{pmatrix}
0&-I_n\\
I_n&0
\end{pmatrix},
\qquad
J_n^2=-I_{2n}.
}
\]

Then multiplication by `i` is exactly

\[
i\psi
\longleftrightarrow
J_nv.
\]

No complex primitive is needed to implement this operation.

# 2. Realifying a complex matrix

Let

\[
H=A+iB
\]

with real matrices `A,B`.

Define

\[
\boxed{
\mathcal R(H)=
\begin{pmatrix}
A&-B\\
B&A
\end{pmatrix}.
}
\]

Then

\[
\boxed{
\mathcal R(H_1H_2)=\mathcal R(H_1)\mathcal R(H_2).
}
\]

Also

\[
\boxed{
\mathcal R(H^\dagger)=\mathcal R(H)^T.
}
\]

Thus the full finite-dimensional complex matrix `*`-algebra embeds exactly into ordinary real matrices.

This is the many-component version of the earlier scalar map

\[
a+bi\mapsto
\begin{pmatrix}
a&-b\\b&a
\end{pmatrix}.
\]

So a complex Hermitian observable is exactly an ordinary **real symmetric matrix** that also commutes with the chosen complex structure `J_n`.

# 4. Schrödinger equation without primitive i

Start from

\[
 i\frac{d\psi}{dt}=H\psi.
\]

Equivalently

\[
\frac{d\psi}{dt}=-iH\psi.
\]

On the real vector `v`, this is

\[
\boxed{
\frac{dv}{dt}
=-J_n\mathcal R(H)v.
}
\]

Define

\[
K=-J_n\mathcal R(H).
\]

Because `H` is Hermitian,

\[
\mathcal R(H)^T=\mathcal R(H),
\]

and because `J_n` is skew-symmetric and commutes with `R(H)`, one gets

\[
\boxed{K^T=-K}.
\]

Thus complex unitary quantum flow is ordinary real orthogonal rotation generated by a skew matrix.

# 5. Norm conservation becomes ordinary Euclidean geometry

For

\[
\dot v=Kv,
\qquad K^T=-K,
\]

we have

\[
\frac{d}{dt}(v^Tv)
=v^T(K^T+K)v=0.
\]

Hence

\[
\boxed{v^Tv=\|\psi\|^2}
\]

is conserved.

The familiar quantum norm preservation therefore has a completely real formulation:


# 6. Symplectic interpretation

The same matrix `J_n` defines the standard symplectic form

\[
\Omega(u,v)=u^T J_n v.
\]

\[
\boxed{

So the complex Schrödinger equation and real linear Hamiltonian mechanics are two exact coordinate languages for the same finite-dimensional flow once a compatible complex structure is supplied.
