# BQG V15 — 32 входа K5: частичный вычислительный аудит

Статус 15.10.2026: 8 из 32 исходных K5 состояний обработаны всеми пятью узловыми операторами H_v; 40 из 160 прямых колонок. Использовался локальный исследовательский mirror V14, не побайтово удостоверенный upstream. Скрипт GitHub импортирует именно scripts/k5_peter_weyl_safe_hda_column.py из checkout и сверяет SHA256 кеша.

## Конечные результаты

- 438 выходных состояний в объединении, включая 32 исходных; 406 вне оригинального сектора.
- 8x8 прямоугольный restricted master Gram имеет ранг 8 и минимальное сингулярное значение 3.2853961046804225.
- Квадрат Фробениусовой нормы полного отображения = 98.3382269154894, старое 32-секторное сжатие даёт ноль.
- Для восьми выбранных входов все 8 нулевых направлений старого сжатия ложны.
- В локальном исследовательском пакете восемь автоматических тестов успешно пройдены. На исходном файле GitHub полный 160-колоночный прогон еще не выполнен.

## Воспроизведение

    OPENBLAS_NUM_THREADS=1 python research/v15_k5_32input/v15_32input.py --output-dir /tmp/bqg_v15 --source-limit 32 --max-new 160 --wall 5

Скрипт сохраняет вычисленные колонки, использует hex-представление комплексных чисел, проверяет SHA-256 upstream и не заменяет незавершённые колонки нулями.

## Открытые условия

1. Все 32 входа, 160 полных прямых колонок, независимый полный обратный аудит.
2. Shell-depth и cutoff сходимость, полное Lorentzian constraint family.
3. Входные графоизменённые секторы для ненулевых межграфовых блоков.
4. Полный физический BQG projector, гравитон и Einstein-Hilbert не вычислены.

Полученная Gram-матрица ограниченного входа — не физический проектор.
