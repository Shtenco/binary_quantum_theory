BQG V21 — численный частичный проход на оригинальном K5.

Восстановлены ВСЕ 720 входных ключей первого shell из 160 канонических V20 колонок: распределение по числу исчезнувших рёбер 320,240,120,40. Но рассчитаны H_v для **65/720** полных входов (325/3600 завершённых колонок) и сохранена ещё одна колонка незавершённого входа #8 — **326/3600 файлов**. Исходник K5 проверен Git blob e7e1e0705c4b833dcee167a2036ef5f8929a4388 и SHA256 596c4179cb2c8af20b41c18b3ab87b711c3850c5c5e05b1bc91a1f87c9f11cc4.

Для 32 исходных плюс 65 новых состояний: Gram 97×97, ранг 97, λmin=5.888331978187632, λmax=14.483850719096251, mixed parity block=0; 10400 сравнений прямых/обратных матричных элементов, 1012 нетривиальных, ошибка не более 3.34e-16. 15/15 локальных тестов PASS.

Полный воспроизводимый архив с 160 V20 каноническими колонками, 326 новыми колонками, всеми входами, npz, checkpoint, Python и SHA манифестом: BQG_V21_K5_First_Shell_65of720.zip — передан в чате. В GitHub находится упрощённый переносимый checkpoint-runner; он НЕ утверждает выполнение остальных 655 состояний.

Исполнять после размещения оригинальных V20 колонок в директории и задания переменных BQG_V20_COLUMNS и BQG_V21_OUTPUT:

OPENBLAS_NUM_THREADS=1 python research/v21_k5_shell/runner_720.py --start 0 --stop 720 --workers 4 --max-new 720

**Не выполнены:** все 720 входов, 3600 колонок, второй shell, сходимость kernel по shell/Jmax, Lorentzian HDA, Pphys, физический spin-2, Einstein–Hilbert. Не подменять недостающие колонки нулями и не использовать этот ограниченный Gram как физический проектор.
