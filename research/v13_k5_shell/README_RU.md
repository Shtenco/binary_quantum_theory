# V13 — K5 master без ложных нулевых мод от сжатия

## Ключевое исправление
Предыдущий `scripts/bqg_k5_graph_sector_master_shell.py` сначала заменял настоящий оператор `C_v` на квадратную матрицу `P_S C_v P_S` и лишь затем строил master. Такое сжатие выбрасывает ненулевые выходы вне shell и может искусственно увеличить размерность kernel.

Новый сборщик хранит **все ненулевые рассчитанные выходы** в строках общей прямоугольной матрицы `C_v: S -> H_out`.

Тогда
```
M_safe = Σ_v C_v† C_v
M_old  = Σ_v (P_S C_v)† (P_S C_v)
M_safe-M_old = Σ_v (P_out C_v)† (P_out C_v) ≥ 0 .
```
Внутри фиксированного пространства входов любая настоящая нулевая мода безопасной формы также является нулевой модой старой сжатой формы. Обратное неверно: **сжатие способно создавать ложные нули**.

## Результаты регрессионных тестов
Локально исполнены 6 тестов, все PASS.
- Преднамеренная ложная мода: старая nullity=2, безопасная nullity=1.
- Настоящая интерференционная нулевая мода: `C|a>=|external>`, `C|b>=-|external>`; ненулевые finite-shell cross-graph blocks сохранены.
- Положительность пропущенного вкладa и контроль потери нормы.
- Контроль прямого и выбранного обратного амплитудного элемента.
- Большое пространство не объявляется нулевым проектором без диагонализации.
- Контроль нулевого оператора.

## ВАЖНО: границы результата
- Сборщик использует **действительный BQG K5 Peter–Weyl backend**, но его полный холодный прогон и полные обратные колонки в этом PR ещё **не проверены**.
- Вызов `C†` — точное сопряжение **посчитанной прямоугольной матрицы**; это не независимое доказательство, что все upstream `apply_H_cached_state` примитивы реализуют глобальный adjoint.
- При превышении `dense_limit` никакой проектор не вычисляется и нулевые моды не выдумываются.
- Входная оболочка, существующие пороги округления и `Jmax` ограничены; конечная ограниченная форма не эквивалентна физическому BQG projector.
- Статические projector/heat-kernel параметры не являются физическим временем. Межграфовые блоки не являются вероятностями физического рождения связей.
- `main` не затрагивается.

## Применение

```bash
python -m unittest research/v13_k5_shell/test_leakage_safe_master.py
python research/v13_k5_shell/bqg_k5_leakage_safe_master.py --depth 0 --jmax2 5 --dense-limit 256 --output /tmp/bqg_k5_v13.json
```
