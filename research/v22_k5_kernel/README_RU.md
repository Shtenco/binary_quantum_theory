# BQG V22 — проверка сходимости ядра K5 (ограниченный результат)

Исходный байтово канонический K5: Git blob `e7e1e0705c4b833dcee167a2036ef5f8929a4388`, SHA256 `596c4179cb2c8af20b41c18b3ab87b711c3850c5c5e05b1bc91a1f87c9f11cc4`.

Продолжены реальные K5-вычисления первого shell: **69 из 720** полных входов (ранее 65). Сохранено **354** из 3600 колонок, из которых **345** принадлежат 69 полностью завершённым входам; 9 находятся у незавершённых. Применяется пять Euclidean H_v. Исходные 160/160 колонок V20 также сохранены.

Ограниченный leakage-safe master `C†C` размером **101×101**, ранг 101, `lambda_min=5.883687739952585`; не найдено нулевой моды. Блоки чётности 32 и 69, запрещённый смешанный блок точно равен 0. Проверены 11040 прямых/обратных элементов, максимум 3.3396e-16.

Последовательность вложенных подпространств первого слоя:
`[n,lambda_min]`: (1,6.94541), (4,6.63627), (8,6.48740), (16,6.25298), (24,6.06525), (32,5.99702), (41,5.98217), (49,5.96457), (65,5.88833), (69,5.88369). Перекрытие низших нормированных векторов 65→69 — 0.99760006, но `||C psi_min||=sqrt(5.88368774)≈2.426` и физической нулевой моды нет.

Новый структурный cutoff-контроль: на первом shell максимальный doubled-spin =2, в одном терме H_v каждое ребро меняется не более чем на 2, поэтому **jmax2=4 (Jmax=2)** достаточен для одного действия H_v на любом входе этого shell. Три оригинальные колонки (0,0), (40,0), (69,0) при jmax2=4 и 5 совпали точно, в то время как jmax2=2 для двух из них теряет ненулевые вклады. Для дальнейших слоёв потребуется более высокий cutoff.

Локальный набор: 8/8 новых синтетических регрессионных тестов PASS, 14/14 ранее действующих тестов PASS и один SKIP (непредоставленная внешняя ссылка). Проверена целостность ZIP с **557 файлами**: полный каталог 720 ключей, оригинал K5, 160 первичных и 354 новых колонок, код, спектральные CSV/PNG/JSON и SHA manifest. ZIP передан в разговоре; в GitHub загружается компактный воспроизводимый анализатор.

**Не доказано:** сходимость ядра по всему 720-входному shell; полный физический проектор P_phys; Lorentzian/HDA, независимый полный adjoint; нормируемость нулевого физического вектора; гравитон и Einstein–Hilbert. Положительная нижняя граница для конечного подпространства НЕ является нижней границей на всем пространстве; `lambda_min→0` само по себе также не доказывает существование нормируемого kernel.
