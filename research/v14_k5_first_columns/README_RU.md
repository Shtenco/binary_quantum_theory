# BQG V14 — холодный расчёт пяти K5-колонок (частичный операторный аудит)

**Статус:** ограниченный воспроизводимый вычислительный результат, **НЕ** полный физический проектор.

## Выполнено 15 октября 2026 года

На CPU исполнена локально переписанная по публичному исходнику `scripts/k5_peter_weyl_safe_hda_column.py` версия исходного алгоритма K5. **Байтовая идентичность локальной копии upstream не удостоверена**. Для точного независимого повтора в этом PR прилагается `k5_v14_cold.py`, который импортирует именно канонический исходник текущего checkout GitHub.

Источник: 10 рёбер K5, удвоенные спины `s=1` (j=1/2), 5 интертвинеров `K=0`. Прямые действия `H_v |ψ_0>` проведены для всех пяти узлов при `Jmax2=5`.

|2|44|2.1787371295851368|33|

Итого 204 выхода с кратностью узлов, 112 различных выходных состояний.
`Σ_v||H_vψ_0||² = 11.369272537539125`. Доля квадрата нормы с хотя бы одним j=0 ребром — **0.3610476287598219**. Это не вероятность рождения графа; её нельзя путать с 44.4033% от исторического расчёта `[H_0,H_1]ψ`.

В одномерном входном shell старое сжатие `P_SH_vP_S` даёт нулевую матрицу и ложную нулевую моду. В точной прямоугольной master-форме **на том же входном секторе** получено `M=[11.369272537539125]`, нулевых мод нет. Это не спектр полного K5.

### Прямые и обратные амплитуды

Независимо применён `H_v` к одному ведущему выходному состоянию для узлов 0,1,2,3. Максимальное расхождение `|<ψ|H_v|φ>-conj(<φ|H_v|ψ>)|` — `3.3325e-16`. Ещё один отдельный локальный контроль v=4 имел расхождение `3.33e-16`, но не входит в кеш четырех узлов этого PR. **Полные обратные колонки не завершены**.

### Отсечение

Для первого действия `H_0|ψ>` результаты при `Jmax2=2` и `Jmax2=5` совпали по 41 компоненте. Это не проверка cutoff для двойных действий HH и не сертификат полного Lorentzian H_L.

### Проверка воспроизводимости

```bash
OPENBLAS_NUM_THREADS=1 python research/v14_k5_first_columns/k5_v14_cold.py --output-dir /tmp/bqg_v14 --jmax2 5 --vertices 0 1 2 3 4 --reverse-per-vertex 1
```

Скрипт хранит комплексные коэффициенты в формате `float.hex`, вычисляет SHA-256 настоящего backend, отказывается от несовместимых кешей, проверяет прямые/обратные выбранные амплитуды.

### Незакрытые условия

- Все 32 входа исходного `j=1/2` сектора, дальнейшие shell-уровни.
- Независимое глобальное сопряжение всех исходящих каналов.
- Сходимость нулевого подпространства по глубине и cutoff.
- Полное Lorentzian constraint family, отсутствие HDA-аномалии.
- Ненулевой физический `P_phys`, метрика 3+1, TT/гравитон, действие Эйнштейна–Гильберта.
