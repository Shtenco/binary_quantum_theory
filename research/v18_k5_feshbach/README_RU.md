# BQG V18 — независимый чётностный Schur/Feshbach контроль

**Научный статус:** строго проверяемая конечная матричная диагностика на сохранённой неканонической исследовательской копии K5. Ни один оператор полного BQG физического проектора не заявлен.

## Результат для V17 36×36
- Чётные и нечётные входы: 33 и 3; смешанный блок M точно нулевой.
- Минимальное собственное значение начального 32D блока: 9.651811183250418.
- Минимум расширенного 33D чётного блока: 8.921640965443077.
- Минимум выбранного 3D нечётного блока: 6.942977490858537.
- При добавлении одного состояния второго шага минимум чётного блока уменьшается на 0.7301702178073413.
- Межграфовый вектор b: Frobenius norm=0.7687827127550354, 12 ненулевых коэффициентов, максимальный модуль 0.4410012328116343.
- Точный Schur при z=0: 9.03759593656682.
- Независимая формула Фешбаха воспроизводит λmin с ошибкой <6×10^-15; резольвенты в трёх точках согласуются до 1.32×10^-16.
- У выбранной 36D матрицы rank=36 и нулевого kernel нет.

Формула: если M_even = [[A,b],[b†,c]], верхний левый блок (M_even−zI)^−1 совпадает с обратной матрицей A−zI−bb†/(c−z). Это математическая формула конечной матрицы, **не** физический отклик или гравитонный пропагатор.

## Данные
Полный reproducibility-пакет вместе с двумя входными NPZ, исходным V17 JSON, картинкой и 19 тестами приложен ZIP в чате. Этот PR добавляет компактный независимый Schur checker и синтетические тесты. Чтобы воспроизвести реальную матричную проверку, предоставьте input NPZ из ZIP.

Команда:
```bash
python research/v18_k5_feshbach/v18_schur_audit.py --v16-npz /path/v16_gram.npz --v17-npz /path/v17_restricted_master.npz --v17-json /path/v17_results.json --output /tmp/v18_schur.json
```

## Открытые вопросы
Небайтово идентичный GitHub upstream, все 720 первых входов, второй shell целиком, обратные колонки, Lorentzian/HDA, физический projector, Einstein–Hilbert и гравитон остаются открыты. **Нельзя** считать Schur-параметр физическим временем, а finite block — массой гравитона.
