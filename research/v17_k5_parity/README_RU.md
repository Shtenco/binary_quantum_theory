# V17 — чётность K5 и ограниченный расширенный shell

Математическая структура выбранного евклидова оператора: три элементарных смены спина на треугольном пути и две на радиальном ребре ⇒ каждое H_v меняет чётность суммы удвоенных спинов: {P,H_v}=0, а M=ΣH_v†H_v сохраняет чётность: [P,M]=0. Отсюда межчётностный блок master равен нулю. Это не утверждение о полном лоренцевом BQG.

Из сохранённых 160 колонок локальной исследовательской реализации восстановлены 720 одношаговых состояний в 51 графовом секторе: графы по числу j=0 рёбер [1,10,30,10], состояния [320,240,120,40]. Два исчезнувших ребра делят вершину, три образуют треугольник.

Вычислен один новый полноценный вход первого shell (5 H_v, число выходов [62,62,63,41,44]); с тремя прежними входами расширения — матрица restricted Gram 36×36, rank 36, lambda_min 6.942977490858538, lambda_max 18.011218063740422. Прямые/обратные тесты 640 пар, из них 39 нетривиальных, максимальная ошибка 3.339612472859851e-16. Локальные автоматические проверки 12/12.

**Не сертифицировано:** локальный исполняемый mirror имеет Git blob 1353c9fd937d5dbc83615fd041dc8df5da3895a2; оригинал GitHub — e7e1e0705c4b833dcee167a2036ef5f8929a4388. Новый `v17_parity_shell_gate.py` принимает только оригинал по умолчанию и требует ровно 160 исходных колонок с проверкой SHA256; численные результаты mirror остаются исследовательскими.

**Не решено:** выполнение всех 720 первых входов, полный второй shell, все reverse, cutoff convergence, физический проектор BQG, гравитон, ОТО. Не трактовать M-блоки как P_phys.
