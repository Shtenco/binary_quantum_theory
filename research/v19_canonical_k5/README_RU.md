## Воспроизводимость
Программа `research/v19_canonical_k5/replay_k5.py` строго сравнивает Git blob оригинала, проверяет SHA-256 старых fixtures и **пересчитывает** все амплитуды выбранных колонок. Повтор можно запускать на рабочей копии репозитория:

```bash
OPENBLAS_NUM_THREADS=1 python research/v19_canonical_k5/replay_k5.py \
 --backend scripts/k5_peter_weyl_safe_hda_column.py \
 --mirror-column-dirs /PATH/TO/V16/columns /PATH/TO/V15/columns \
 --output-dir /tmp/bqg_v19_checked
```

Для полных 160 колонок необходимо указать все 160 пар и независимо пройти весь расчёт на оригинале; текущая команда лишь проверяет выборку. При отсутствии исходной колонки/fixture программа завершится с ошибкой вместо подстановки нуля.

## Научные ограничения

- **12/160**, а не 160/160 воспроизведены заново на оригинале для смешанного набора; конкретно первоначальных — **6/160**. Численные значения V16 полного 32×32 Gram по-прежнему происходят из mirror.
- Два выбранных входа первого shell не равны всем 720 возможным входам. Прямые колонки второго shell целиком не получены.
- Выборочные совпадения не подтверждают полное глобальное сопряжение, отсутствие HDA аномалии или устойчивость предельного ядра.
- Без устойчивого физического ядра полного семейства ограничений (P_{phys}) и связанные физические межграфовые амплитуды не вычислены.
- Ни безмассовый тензорный гравитон, ни действие Einstein–Hilbert не получены.

**Следующий вычислительный рубеж:** закончить все 160 независимых канонических колонок и полные прямые/сопряжённые образы первого shell, не используя старый Gram как сертификат нового расчёта.
