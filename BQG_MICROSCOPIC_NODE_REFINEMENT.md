# BQG microscopic node-refinement pure-ancilla test

Status: **NO-GO / finite exact counterexample to the naive fixed-pure-ancilla construction.**

The first attempted microscopic refinement was:

\[
\text{old four-spin-}\frac12\text{ singlet}
+
\text{one fixed fresh four-spin-}\frac12\text{ ancilla singlet}
\]

followed by edgewise symmetric blocking

\[
V_{1/2}\otimes V_{1/2}\to V_1
\]

and projection to the coarse spin-1 Gauss singlet space.

The question was whether one fixed ancilla singlet \(|\chi\rangle\) could induce
the already registered canonical linear intertwiner

\[
W=
\begin{pmatrix}
0&2/3\\
1&0\\
0&-\sqrt5/3
\end{pmatrix}.
\]

The exact finite gate returned:

\[
\boxed{\text{relative reconstruction error}=1}
\]

and

\[
\boxed{\text{phase-fixed error}=\sqrt2.}
\]

The two microscopic maps generated by the two ancilla-singlet basis vectors
span a two-dimensional space, but the canonical \(W\) is not in that span.

This is not a numerical-conditioning issue:

- Gauss-projection leakage is
  \[
  3.43\times10^{-31};
  \]
- the microscopic map basis is full rank in its two-dimensional span;
- the failure is representation-theoretic.

The reason is now understood exactly.  The ancilla Gauss-singlet space itself
transforms as \(S_4[2,2]\) and has no nonzero invariant vector.  Therefore
choosing a fixed pure ancilla state necessarily breaks tetrahedral permutation
symmetry.

Hence

\[
\boxed{
\text{fixed pure ancilla state}
\not\Rightarrow
\text{canonical }S_4\text{-equivariant linear refinement map}.
}
\]

The correct microscopic object is instead the bilinear refinement tensor

\[
\boxed{
[2,2]_{\rm old}\otimes[2,2]_{\rm anc}
\to
[2,2]_{\rm coarse},
}
\]

which is treated and verified in

- \`BQG_MICROSCOPIC_BILINEAR_REFINEMENT_THEOREM.md\`
- \`scripts/bqg_microscopic_bilinear_refinement_gate.py\`.

This NO-GO removes an incorrect shortcut but leaves the binary-ancilla
refinement programme intact in its correct bilinear/Stinespring form.
